# Changelog

## kuenm2 0.1.5 (in development)

- Significantly reduced model calibration runtime through four internal
  optimizations (with no changes to numerical outputs). (1) Formula
  grouping: Models sharing the same formula now compute design matrices
  and regularization penalties only once, reusing them across all
  regularization multipliers. (2) Direct coefficient extraction:
  Extracted final-lambda coefficients directly from glmnet objects
  instead of constructing full 200-lambda sparse matrices.(3)
  Matrix-based fold predictions: Computed cross-validation predictions
  via direct matrix multiplication rather than rebuilding feature
  matrices for each fold.(4) Lightweight fold fitting: Added
  `only_fit = TRUE` to skip computing auxiliary (and non-essential)
  model metadata (e.g., variable ranges, sample means, entropy) during
  cross-validation folds.
- Replaced doSNOW and foreach with pbapply across all parallelized
  functions
  ([`calibration()`](https://marlonecobos.github.io/kuenm2/reference/calibration.md),
  [`partial_roc()`](https://marlonecobos.github.io/kuenm2/reference/partial_roc.md),
  [`variable_importance()`](https://marlonecobos.github.io/kuenm2/reference/variable_importance.md),
  [`project_selected()`](https://marlonecobos.github.io/kuenm2/reference/project_selected.md),
  [`select_models()`](https://marlonecobos.github.io/kuenm2/reference/select_models.md),
  and
  [`partition_response_curves()`](https://marlonecobos.github.io/kuenm2/reference/partition_response_curves.md)).
- Replaced
  [`utils::txtProgressBar()`](https://rdrr.io/r/utils/txtProgressBar.html)
  with pbapply across functions
  ([`predict_selected()`](https://marlonecobos.github.io/kuenm2/reference/predict_selected.md),
  [`organize_future_worldclim()`](https://marlonecobos.github.io/kuenm2/reference/organize_future_worldclim.md),
  [`perform_pca()`](https://marlonecobos.github.io/kuenm2/reference/perform_pca.md),
  [`projection_variability()`](https://marlonecobos.github.io/kuenm2/reference/projection_variability.md),
  [`projection_mop()`](https://marlonecobos.github.io/kuenm2/reference/projection_mop.md),
  and
  [`explore_partition_extrapolation()`](https://marlonecobos.github.io/kuenm2/reference/explore_partition_extrapolation.md)).
- Improving execution speed and bug handling with large rasters in
  [`project_selected()`](https://marlonecobos.github.io/kuenm2/reference/project_selected.md).

## kuenm2 0.1.4

CRAN release: 2026-11-06

- In
  [`prediction_changes()`](https://marlonecobos.github.io/kuenm2/reference/prediction_changes.md)
  and
  [`projection_changes()`](https://marlonecobos.github.io/kuenm2/reference/projection_changes.md),
  use
  [`terra::compareGeom()`](https://rspatial.github.io/terra/reference/compareGeom.html)
  instead of
  [`terra::res()`](https://rspatial.github.io/terra/reference/dimensions.html)
  and
  [`terra::ext()`](https://rspatial.github.io/terra/reference/ext.html)
  to compare bounding boxes and resolution.
- Fix issue [\#118](https://github.com/marlonecobos/kuenm2/issues/118)
  with hinge feature treatment in
  [`calibration()`](https://marlonecobos.github.io/kuenm2/reference/calibration.md)
  and response_curves
- New function:
  [`replace_partition()`](https://marlonecobos.github.io/kuenm2/reference/replace_partition.md)
  replaces test partitions in a `prepared_data()` object with spatial
  partitions generated by ENMeval or flexsdm.
- Add variables argument to
  [`plot_calibration_hist()`](https://marlonecobos.github.io/kuenm2/reference/plot_calibration_hist.md)
  to allow subsetting variables to plot and arguments to display a
  legend for bar colors
- Fix bug in
  [`import_results()`](https://marlonecobos.github.io/kuenm2/reference/import_results.md)
  when importing MOP results from past projections.
- Add legend_bar_spacing argument to
  [`plot_explore_partition()`](https://marlonecobos.github.io/kuenm2/reference/plot_explore_partition.md)
  to control spacing between the color bar and its numeric labels.
- Fix error in event names in
  [`binarize_changes()`](https://marlonecobos.github.io/kuenm2/reference/binarize_changes.md).
- Fix bug in
  [`independent_evaluation()`](https://marlonecobos.github.io/kuenm2/reference/independent_evaluation.md),
  so evaluation works when there are no replicates in the fitted model.
- Increased functionality of
  [`bivariate_response()`](https://marlonecobos.github.io/kuenm2/reference/bivariate_response.md),
  now it: uses breaks to define the number of color levels when using
  default colors, allows the direct use of sets of colors for
  suitability, permits controlling extrapolation factor, uses a relevant
  omission error informed threshold to define limits of suitability.

## kuenm2 0.1.3

CRAN release: 2026-04-20

- In
  [`bivariate_response()`](https://marlonecobos.github.io/kuenm2/reference/bivariate_response.md),
  store and restore graphical parameters only when plotting area is
  modified.
- In `response_curves()`, omit graphical parameter storing and resetting
  to allow plotting in multipanel figures.
- In
  [`projection_changes()`](https://marlonecobos.github.io/kuenm2/reference/projection_changes.md),
  create `data.frame` to set levels representing changes outside of the
  loop. This ensures it works correctly even when `by_gcm` is set to
  `FALSE`.
