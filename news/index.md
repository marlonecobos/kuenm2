# Changelog

## kuenm2 0.1.4

- New function:
  [`replace_partition()`](https://marlonecobos.github.io/kuenm2/reference/replace_partition.md)
  replaces test partitions in a prepared_data object with spatial
  partitions generated by ENMeval or flexsdm.
- Add variables argument to
  [`plot_calibration_hist()`](https://marlonecobos.github.io/kuenm2/reference/plot_calibration_hist.md)
  to allow subsetting variables to plot and arguments to display a
  legend for bar colors
- Fix bug in
  [`import_results()`](https://marlonecobos.github.io/kuenm2/reference/import_results.md)
  when importing MOP results from past projections.
- Add legend_bar_spacing argument to
  [`plot_explore_partition()`](https://marlonecobos.github.io/kuenm2/reference/plot_explore_partition.md)
  to control spacing between the color bar and its numeric labels.
- Fix error in event names in
  [`binarize_changes()`](https://marlonecobos.github.io/kuenm2/reference/binarize_changes.md).
- Fix bug in
  [`independent_evaluation()`](https://marlonecobos.github.io/kuenm2/reference/independent_evaluation.md),
  so evaluation works when there are no replicates in the fitted model.

## kuenm2 0.1.3

CRAN release: 2026-04-20

- In
  [`bivariate_response()`](https://marlonecobos.github.io/kuenm2/reference/bivariate_response.md),
  store and restore graphical parameters only when plotting area is
  modified.
- In `response_curves()`, omit graphical parameter storing and resetting
  to allow plotting in multipanel figures.
- In
  [`projection_changes()`](https://marlonecobos.github.io/kuenm2/reference/projection_changes.md),
  create `data.frame` to set levels representing changes outside of the
  loop. This ensures it works correctly even when `by_gcm` is set to
  `FALSE`.
