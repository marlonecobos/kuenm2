# kuenm2 0.1.5 (in development)
* Significantly reduced model calibration runtime through four internal optimizations (with no changes to numerical outputs). (1) Formula grouping: Models sharing the same formula now compute design matrices and regularization penalties only once, reusing them across all regularization multipliers. (2) Direct coefficient extraction: Extracted final-lambda coefficients directly from glmnet objects instead of constructing full 200-lambda sparse matrices.(3) Matrix-based fold predictions: Computed cross-validation predictions via direct matrix multiplication rather than rebuilding feature matrices for each fold.(4) Lightweight fold fitting: Added `only_fit = TRUE` to skip computing auxiliary (and non-essential) model metadata (e.g., variable ranges, sample means, entropy) during cross-validation folds.
* Replaced doSNOW and foreach with pbapply across all parallelized functions (`calibration()`, `partial_roc()`, `variable_importance()`, `project_selected()`, `select_models()`, and `partition_response_curves()`).
* Replaced `utils::txtProgressBar()` with pbapply across functions (`predict_selected()`, `organize_future_worldclim()`, `perform_pca()`, `projection_variability()`, `projection_mop()`, and `explore_partition_extrapolation()`).
* Improving execution speed and bug handling with large rasters in `project_selected()`.

# kuenm2 0.1.4
* In `prediction_changes()` and `projection_changes()`, use `terra::compareGeom()` instead of `terra::res()` and `terra::ext()` to compare bounding boxes and resolution.
* Fix issue #118 with hinge feature treatment in `calibration()` and response_curves
* New function: `replace_partition()` replaces test partitions in a `prepared_data()` object with spatial partitions generated by ENMeval or flexsdm.
* Add variables argument to `plot_calibration_hist()` to allow subsetting variables to plot and arguments to display a legend for bar colors
* Fix bug in `import_results()` when importing MOP results from past projections.
* Add legend_bar_spacing argument to `plot_explore_partition()` to control spacing between the color bar and its numeric labels.
* Fix error in event names in `binarize_changes()`.
* Fix bug in `independent_evaluation()`, so evaluation works when there are no replicates in the fitted model.
* Increased functionality of `bivariate_response()`, now it: uses breaks to define the number of color levels when using default colors, allows the direct use of sets of colors for suitability, permits controlling extrapolation factor, uses a relevant omission error informed threshold to define limits of suitability.
